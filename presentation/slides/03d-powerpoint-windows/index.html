Install locally on Windows

PowerPoint for Windows loads sideloaded add-ins from a trusted shared-folder catalog.

  1. 1

    Download the manifest

    Right-click Download manifest.xml, choose Download Linked File As… (or Save link as…), and save it as manifest.xml.

  2. 2

    Create a shared catalog

    Create a dedicated folder, copy manifest.xml into it, then choose Properties > Sharing > Share. Note its network path.

  3. 3

    Trust the catalog

    Choose File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs. Add the network path, enable Show in Menu, and restart PowerPoint.

  4. 4

    Add DICOM Slides

    Choose Home > Add-ins > Advanced > SHARED FOLDER, select DICOM Slides, and choose Add.

Read Microsoft's Windows sideloading guide.
