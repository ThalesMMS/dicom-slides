Why Windows needs one extra step

DICOM Slides is the same add-in on every platform. Only the way PowerPoint accepts its installation file changes.

manifest.xml is a small XML file that tells PowerPoint where to find DICOM Slides. It does not contain the add-in or an exam.

PowerPoint online lets you upload that file directly. PowerPoint for Mac checks its own local add-ins folder.

PowerPoint for Windows only lists an XML add-in after you approve the folder that contains its manifest.

Microsoft calls the approved folder a Trusted Add-in Catalog. Despite the name, it is simply a shared folder that PowerPoint is allowed to check.
