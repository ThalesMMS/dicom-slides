Install locally on Windows

You only need to approve the folder once. After that, DICOM Slides behaves like any other PowerPoint add-in.

  1. 1

    Download the small manifest

    Right-click Download manifest.xml, choose Download Linked File As… (or Save link as…), and save it as manifest.xml.

  2. 2

    Create and share its folder

    Create a folder for DICOM Slides, move manifest.xml into it, then choose Properties > Sharing > Share. Copy the folder address Windows displays.

  3. 3

    Show the folder to PowerPoint

    Choose File > Options > Trust Center > Trust Center Settings > Trusted Add-in Catalogs. Paste the folder address, choose Add catalog, enable Show in Menu, and restart PowerPoint.

  4. 4

    Open DICOM Slides

    Choose Home > Add-ins > Advanced > SHARED FOLDER, select DICOM Slides, and choose Add.
